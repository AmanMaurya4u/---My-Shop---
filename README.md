# Arun Electronics Website,,,,,,,

## 📌 Project Overview

Arun Electronics Website is a modern, responsive electronics store website developed for **Arun Electronics**, located in **Gopiganj, Bhadohi, Uttar Pradesh**. The website provides customers with an easy way to explore products, view repairing services, contact the shop, and receive AI-powered product recommendations.

This project is built using **HTML, CSS, and JavaScript** and is designed to provide a professional digital presence for a local electronics business.

---

## 🚀 Features

### 🏪 Electronics Product Catalog

Browse a wide range of electronic and electrical products including:

* Switches
* Sockets
* Plugs
* Fuses
* LED Bulbs
* Tube Lights
* Electric Wires
* MCB & RCCB

* Coolers
* Refrigerators
* Washing Machines

* Inverters

* D2H Set-top Boxes

### 🔍 Smart Product Search

Customers can instantly search products by name and find relevant items quickly.

### 🧠 AI Assistant

An AI-powered helper recommends products and services based on customer requirements.

Examples:

* "I need cooling products" → AC, Cooler, Fan
* "Need power backup" → Inverter, Battery, UPS
* "TV not working" → TV Repair Service

Customers can directly contact the shop and request product prices through WhatsApp.

### 🖼 Gallery Section

Displays shop images, products, and service-related photos.

### 📍 Contact & Location

Includes shop details, contact information, and Google Maps integration.

Optimized for:
